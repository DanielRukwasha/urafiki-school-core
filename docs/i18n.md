# Internationalisation (invariant 11)

Socle livré par l'agent Backend ; le marquage des gabarits revient à
l'agent Frontend.

## Principes

- **Flask-Babel**, configuré dans `app/i18n.py`. Le français est la langue de
  référence : chaque identifiant de message (msgid) est le texte français.
  Une chaîne non traduite s'affiche donc correctement en français.
- **La langue d'une requête est celle du tenant** (`Institution.locale`, en
  base, invariant 2). Un tenant configuré dans une langue que la plateforme
  ne propose pas (`LANGUES_DISPONIBLES` dans `app/config.py`) lève
  `LangueNonDisponibleError` : jamais de repli silencieux.
- **Aucune chaîne affichée en dur.** Gabarits : `{{ _("Texte") }}`, ou
  `{% trans %}…{% endtrans %}` pour un bloc. Python : `gettext` /
  `lazy_gettext` (importé `_l`) de `flask_babel`, `_l` pour une chaîne
  définie au chargement du module (libellés de formulaire, constantes).

## Fichiers

```
babel.cfg                                 règles d'extraction
app/translations/messages.pot             modèle (toutes les chaînes marquées)
app/translations/fr/LC_MESSAGES/messages.po   catalogue français (référence)
app/translations/<langue>/LC_MESSAGES/messages.mo   compilé, NON versionné
```

Les `.mo` sont compilés au déploiement et en CI (`pybabel compile`), jamais
versionnés.

## Mettre à jour les catalogues (après avoir marqué de nouvelles chaînes)

```bash
pybabel extract -F babel.cfg -k _l -k lazy_gettext --no-location --sort-output \
  --project=urafiki-school-core --copyright-holder=Urafiki \
  -o app/translations/messages.pot .
pybabel update -i app/translations/messages.pot -d app/translations
pybabel compile -d app/translations
```

`tests/integration/test_i18n.py::test_french_catalog_covers_every_marked_string`
échoue tant que ces commandes n'ont pas été passées : un catalogue en retard
sur le code est détecté en CI.

## Ajouter le swahili (aucune modification de code)

```bash
pybabel init -i app/translations/messages.pot -d app/translations -l sw
# traduire app/translations/sw/LC_MESSAGES/messages.po
pybabel compile -d app/translations
```

Puis passer `Institution.locale` à `"sw"` pour le tenant concerné. Le test
`test_adding_swahili_needs_only_a_catalog` démontre ce parcours.
